# Purpose

Protects exit SELLs from MooMoo's pending-order position lock. The broker's
`can_sell_qty` can drop while another SELL is pending even though the holding
`qty` is unchanged.

# Behaviour

`runSellableQtyGuard()` in `magi-core/src/sellGuard.js` clamps an exit SELL to
`can_sell_qty`. When nothing is sellable it blocks outright. Without this
guard, sizing from the full holding produced broker HTTP 500
`"Not enough positions"` responses and retry loops.
The expected block identifier is `sellable_qty_layer`.

# Constitution basis

[POSITION MANAGEMENT](/system/constitution/position-management.md): exit
orders must be limited to the quantity the broker can currently sell.
