# Purpose

The first gate: verifies the broker connection is available and the instrument
is tradable before any further evaluation. Prevents wasted work and phantom
orders when the broker (Alpaca / MooMoo) is down.

# Behaviour

On failure the call returns `blocked_by: 'broker_guard'` and no order is placed.
