# Purpose

Checks `checkDailyLossKillSwitch(unitName)` in
`magi-core/lib/daily-loss.js`. It sums the unit's realized P&L for the current
Eastern Time day and compares it with `-DAILY_LOSS_LIMIT_USD`.

# Behaviour

At or beyond the limit, risk-increasing orders are blocked for the rest of the
trading day with `blocked_by: 'daily_loss_kill_switch'`. The response echoes
`realized_pnl_usd` and `limit_usd`. Risk-reducing orders still pass so exposure
can always be unwound. A position-lookup failure fails closed and treats the
order as risk-increasing. `notifyKillSwitchOnce()` alerts once per unit.

The switch is per-unit, not portfolio-wide.

# Constitution basis

[POSITION MANAGEMENT](/system/constitution/position-management.md): daily
loss protection must stop additional exposure while preserving the ability to
close positions.
