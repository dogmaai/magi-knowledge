# Purpose

Enforces the cash-account rule when `ACCOUNT_TYPE=cash` (the default is
`margin`). A SELL on a symbol with no held long position would create a new
short entry and is not permitted in a cash account.

# Behaviour

The guard uses `isHeldPosition()`. New short-entry SELLs are blocked with
`blocked_by: 'cash_account_guard'`; SELLs that close an existing long position
pass through.

# Constitution basis

[POSITION MANAGEMENT](/system/constitution/position-management.md): cash
accounts may only open with BUY and may SELL to close or reduce held longs.
