# Purpose

Enforces the cash-account rule. A SELL on a symbol with no held long
position would create a new short entry and is not permitted in a cash
account.

# Account policy (Jun, 2026-10-27)

* Short selling is not used. The only live target is the **cash account**
  (現物口座).
* The short path is retained solely for a future **margin account**
  (信用口座) and is enabled only by an explicit `ACCOUNT_TYPE=margin`.
* Fail-safe default (magi-core PR pending, `lib/account-type.js`): unset,
  empty or unrecognised `ACCOUNT_TYPE` resolves to `cash`. Before that change
  the code default was `margin`; every unit session has carried
  `ACCOUNT_TYPE=cash` since magi-core#631 (2026-10-19). The 2026-10-07 NKE
  840-share short (QWEN, sell 332723 / cover 332758) predates #631 and is a
  policy violation recorded in the [trades](/system/echidna-tables/trades.md)
  vocabulary notes.

# Behaviour

The guard uses `isHeldPosition()`, which checks a session-scoped set in
`src/llm.js` (`heldSymbols`) that is populated when the LLM calls the
`get_positions` tool during the session. New short-entry SELLs are blocked
with `blocked_by: 'cash_account_guard'`; SELLs that close an existing long
position pass through. Caveat: because the held set is populated only by
`get_positions` calls, a session that never queries positions cannot prove a
SELL is an exit — the guard then treats it as a new short and blocks it.

# Constitution basis

[POSITION MANAGEMENT](/system/constitution/position-management.md): cash
accounts may only open with BUY and may SELL to close or reduce held longs.
