# Purpose

Enforces a symbol exclusion list **in code** (not just in the prompt). The list
is data-driven from the `L3_EXCLUDED_SYMBOLS` row in
[optuna-params](/system/echidna-tables/optuna-params.md) (frozen — Optuna
re-optimization is disabled).

**Warn-only mode available as opt-in** (magi-core#548 / magi-knowledge Issue
#99 Fable review): the list was fitted on a small, partly retired-model
sample, so a hard block is not evidence-backed. Setting `L3_WARN_ONLY=true`
lets an exposure-increasing order on an excluded symbol proceed while the
would-be block is journaled as a `WARN_ONLY` guard row (`concerns='L3'`) for
counterfactual outcome measurement — the constitution prompt renders the list
as `ADVISORY (L3)` in this mode. **Production status (magi-core#565, merged
2026-10-03 by Jun): all six LIVE units run with `L3_WARN_ONLY=true`** for the
counterfactual measurement window. The flag default and the code-level
`on_fail` remain `block`; the formal demotion decision and independent
review are still pending — see [guards index](index.md). Exits on existing
positions are always allowed.

# Execution order

In `src/llm.js`, L3 runs immediately after [L1](l1.md) and before
[L1.5](l1-5.md), despite the numeric label.

# Constitution basis

[TRADING UNIVERSE](/system/constitution/trading-universe.md): the prompt declares
`BLOCKED (L3): ...` and this guard enforces it in code so units cannot bypass
the exclusion by ignoring the prompt text.
