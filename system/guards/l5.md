# Purpose

Compares the current reasoning embedding against historical losing reasonings
(ISABEL lose centroids). If the thought is too similar to patterns that have
historically lost, the trade is blocked — preventing the system from repeating
known-bad reasoning.

# Implementation

`runL5Guard(guardCtx)` in `src/paperGuards.js`, using the embeddings cache and
the lose centroids from [isabel-patterns](/system/echidna-tables/isabel-patterns.md).
