# Purpose

Compares the current reasoning embedding against historical losing reasonings
(ISABEL lose centroids). If the thought is too similar to patterns that have
historically lost, the trade **was designed to be** blocked. **Currently
warn-only in the implementation** (`magi-core @ baa5388`): the guard logs a
`[L5] WARNING` and journals a `WARN_ONLY` row (`logGuardBlock`,
`isWarnOnly: true`), then always returns null so the trade proceeds.
Re-promotion to blocking is a demotion decision pending independent review
(see [guards/index](/system/guards/index.md)).

# Implementation

`runL5Guard(guardCtx)` in `src/paperGuards.js`, using the embeddings cache
(`getEmbeddingsCache`, `predictWinProbability`) loaded from the
`thought_embeddings` table (`magi-core/lib/embeddings.js`); per-provider
pattern summaries live in
[isabel-patterns](/system/echidna-tables/isabel-patterns.md)
(`isabel_l4_patterns`).

# Constitution basis

[PROHIBITIONS](/system/constitution/prohibitions.md): "no repeating your own
proven losing patterns (ISABEL flags them)." L5 is the programmatic enforcement
of this prohibition via embedding similarity.
