# Purpose

The final gate: a composite score combining the upstream signals (confidence,
win-probability, similarity, regime) against an Optuna **1000-trial** optimized
threshold. Also the layer where ISABEL synthesis judging incorporates units
such as [TYPHON](/system/plm-units/typhon.md).

# Implementation

`runL7Guard(guardCtx)` in `src/paperGuards.js`; uses `predictWinProbability` and
the Optuna params/weights from
[optuna-params](/system/echidna-tables/optuna-params.md).
