# Purpose

The final gate: a composite score combining the upstream signals (confidence,
win-probability, similarity, regime) against an Optuna **1000-trial** optimized
threshold. **Currently warn-only in the implementation** (`magi-core @
baa5388`): a below-threshold composite score is logged and journaled as a
`WARN_ONLY` row, then the trade proceeds — re-promotion to blocking is a
demotion decision pending independent review (see
[guards/index](/system/guards/index.md)). Optuna re-optimization is frozen
since 2026-10-02, so the tuned threshold is static. Also the layer where
ISABEL synthesis judging incorporates units such as
[TYPHON](/system/plm-units/typhon.md).

# Implementation

`runL7Guard(guardCtx)` in `src/paperGuards.js`; uses `predictWinProbability` and
the Optuna params/weights from
