# Purpose

Blocks a provider/side combination that has underperformed and been placed on
probation. State is persisted in
[l4-probation](/system/echidna-tables/l4-probation.md): a blocked combo must
accrue `probation_passes_this_month` before it trades that side again.

# Implementation

`runL4Guard(guardCtx)` in `src/paperGuards.js`. The guard context carries the
unit's ISABEL stats, last reasoning/confidence, VIX regime, and Optuna params.
An exit on a held position is exempt (the session position cache distinguishes
opens from exits).
