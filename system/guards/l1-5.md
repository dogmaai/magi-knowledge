# Purpose

Hard position-sizing limits, checked against live broker account/positions
(MooMoo):

* **Max concurrent positions** — `MAX_CONCURRENT_POSITIONS`. New opens blocked
  when at the limit (`blocked_by: 'position_limit_layer'`).
* **Max per-position exposure** — `MAX_POSITION_PCT` (0.15) of equity,
  multiplied by the current VIX regime's position multiplier
  (defaults `CALM`/`LOW_FEAR` 1.0, `HIGH_FEAR` 0.7, `EXTREME_FEAR`/`PANIC`
  0.3 — `POSITION_MULTIPLIER_BY_LEVEL` in `magi-core/lib/vix.js`, overridable
  per level by a `POSITION_MULTIPLIER` row in
  [optuna-params](/system/echidna-tables/optuna-params.md) — **except
  `EXTREME_FEAR`, which is locked at 0.3 during the L6 policy validation
  period**, Jun 2026-10-12), so the default effective cap is
  15% / 10.5% / 4.5% of equity. The multiplier scales the cap only — it is
  never also applied to the order quantity. Under the new L6 policy
  (`L6_POLICY=live`, see [L6](l6.md)) an `EXTREME_FEAR` order that exceeds
  the cap is **clamped to the allowed qty** for any order kind — a
  zero-headroom order is skipped; existing positions over the cap are
  never force-liquidated by this layer. Oversized orders are blocked and a
  `max_qty` is returned (`blocked_by: 'position_size_layer'`). A boosted
  (L2.6 confidence-band) order whose boost alone exceeds the cap is clamped
  back to `max_qty` instead and journaled as a `WARN_ONLY` row.

Both limits apply to orders that increase exposure on either side (BUY adding
long, SELL opening/adding short); orders that reduce or close a position pass
so risk can always be unwound. The concurrent-position count is the live
broker account, shared by every unit trading that account.

# Behaviour

The check is fail-safe: if the live broker lookups (account, positions, quote)
error, it logs and is non-blocking (does not falsely block on infrastructure
hiccups). Errors in the guard's own evaluation propagate (fail closed). When no
VIX regime is cached the multiplier defaults to 1.0.

# Constitution basis

[POSITION MANAGEMENT](/system/constitution/position-management.md): max per
symbol 15% of capital, max concurrent 5 symbols. This guard enforces those
limits programmatically. [MARKET REGIME AWARENESS - VIX](/system/constitution/vix-regime.md)
supplies the per-regime size reduction applied to the exposure cap.
