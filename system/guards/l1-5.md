# Purpose

Hard position-sizing limits, checked against live broker account/positions
(MooMoo):

* **Max concurrent positions** — `MAX_CONCURRENT_POSITIONS`. New opens blocked
  when at the limit (`blocked_by: 'position_limit_layer'`).
* **Max per-position exposure** — `MAX_POSITION_PCT` of equity. Oversized orders
  blocked and a `max_qty` is returned (`blocked_by: 'position_size_layer'`).

# Behaviour

The check is fail-safe: if the live position lookup errors, it logs and is
non-blocking (does not falsely block on infrastructure hiccups).
