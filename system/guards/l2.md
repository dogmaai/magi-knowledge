# Purpose

Requires `confidence >= L2_THRESHOLD`, where the threshold was Optuna-optimized
(now frozen — Optuna re-optimization is disabled) and read from
[optuna-params](/system/echidna-tables/optuna-params.md).

**Demoted to warn-only** (magi-core#548 / magi-knowledge Issue #99 Fable
review): the threshold was fitted largely on retired-model samples, so a hard
block is not evidence-backed. A sub-threshold order proceeds and the would-be
block is journaled as a `WARN_ONLY` guard row (`concerns='L2'`) for
counterfactual outcome measurement. Setting `L2_WARN_ONLY=false` restores the
previous hard block (`blocked_by: 'confidence_layer'`).

Before the final confidence check, L2.6 / L2.7 adjust entry-only quantity:

* **Confidence-band sizing** (`magi-core/lib/confidence-band-guard.js`):
  * `0.80 <= confidence < 0.90` → size multiplied by `0.5` (`CONF_BAND_SIZE_MULT`).
  * `confidence >= 0.90` → size multiplied by `1.2` (`CONF_BOOST_MULT`); the
    boosted quantity is still clamped to the L1.5 max-position cap.
* **Short entry sizing** (`magi-core/lib/short-entry-guard.js`): exposure-
  increasing `SELL` orders are sized at `0.7x` (`SHORT_SIZE_MULT`). SELLs that
  reduce an existing long position are not resized.
* **Concerns soft penalty** (`magi-core/lib/concerns-guard.js`): if `concerns`
  text exceeds `200` characters (`CONCERNS_MAX_LEN`) or `concerns`/`reasoning`
  length ratio exceeds `1.0` (`CONCERNS_RATIO_MAX`), confidence is reduced by
  `0.15` (`CONCERNS_PENALTY`) before L2 / L7. This makes the
  [CONCERNS ARE VETO SIGNALS](/system/constitution/concerns-veto.md) rule
  actionable without a hard block.

# Constitution basis

[EXPECTANCY DISCIPLINE](/system/constitution/expectancy.md): "size by edge —
commit more capital to high-conviction setups; commit little or nothing to
marginal ones." L2 enforces the minimum conviction threshold; L2.6/2.7 size by
that conviction and by short-side asymmetry.

[POSITION MANAGEMENT](/system/constitution/position-management.md): short
entries carry smaller size and a tighter stop-loss.
