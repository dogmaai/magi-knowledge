# Purpose

Applies VIX-regime awareness (MAGI-GE-DESIGN-001-v2 §5.2). Jun decided on
2026-10-12 to change the L6 policy: VIX alone no longer vetoes a direction
in `EXTREME_FEAR`, and `PANIC` hardens to block risk-increasing orders on
**both** sides. The rollout keeps the previous rule selectable at runtime.

## New policy (`L6_POLICY=live`)

- `EXTREME_FEAR` (25 <= VIX < 30): BUY and SHORT are both allowed when the
  other guards pass — no VIX-only veto. The fixed 0.3x multiplier applies to
  the **account-wide per-symbol exposure cap** only (15% x 0.3 = **4.5% of
  equity**); it is never also applied to the order quantity itself
  (no double application). An oversize order is **clamped to the allowed
  qty**; zero headroom means skip (block). A position already above the cap
  is never force-liquidated by this change.
- `PANIC` (VIX >= 30): risk-increasing orders blocked in **both** directions —
  new BUY, new SHORT, adds to longs/shorts, and flips (a counter-direction
  order larger than the held position counts as risk-increasing via
  `isIncreasingExposure`, not as a reduction). Long-reducing SELLs and
  short-cover BUYs are not gated by L6.
- `HIGH_FEAR` and below: unchanged — warn-only on BUY; sizing controls and
  Optuna `POSITION_MULTIPLIER` overrides behave as before.

## Modes (`L6_POLICY`, default `legacy`)

| Mode | Enforcement | Journaling |
|---|---|---|
| `legacy` | pre-2026-10-12 rule: `EXTREME_FEAR`/`PANIC` hard-block BUYs; SELL ungated | `BLOCKED` rows as before |
| `observe` | identical to `legacy` — real order decisions do not change | per-order new-policy verdict + allowed qty journaled as `WARN_ONLY` `thoughts` rows (`L6_OBSERVE` marker); EXTREME_FEAR BUY candidates that legacy blocks but the new policy would allow/clamp are additionally journaled to `trades_shadow`/`thoughts_shadow` with `trade_mode='L6_OBSERVE'` so `magi-shadow-evaluator` scores the counterfactual |
| `live` | the new policy above | `BLOCKED` / clamp `WARN_ONLY` rows as before |

Rollback is `L6_POLICY=legacy` (or unset) + redeploy — a code/config change
only. `observe` is **not** a warn-only pass-through: legacy enforcement stays
in effect while observations are recorded, so observation mode itself never
places additional real orders.

Initial deployment runs `observe` on all six live units (`L6_POLICY=observe`
in `deploy.yml`). LIVE adoption is a separate step after the observation
review. The EXTREME_FEAR multiplier is locked at 0.3 during validation —
`POSITION_MULTIPLIER` rows in [optuna-params](/system/echidna-tables/optuna-params.md)
cannot override it (other regimes still override).

## Evaluation plan (Jun 2026-10-12)

Compare old vs new policy at the same decision points and exit rules:
candidate count, cost-inclusive P&L, drawdown and open-position count —
shadow candidates (`trades_shadow` `L6_OBSERVE` rows) for blocked BUYs, real
trades annotated by `L6_OBSERVE` journal rows for the rest. Review ~1 month
after observation starts; insufficient samples → hold the conclusion.

risk-rules doc itself is unchanged and still governs the LILITH lane.
