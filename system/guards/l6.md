# Purpose

Applies VIX-regime awareness (MAGI-GE-DESIGN-001-v2 §5.2). Unlike most layers,
L6 is **warn-only** for BUYs on the standard LLM path: a BUY in an
`EXTREME_FEAR` / `PANIC` regime is allowed but logged to
[`thoughts`](/system/echidna-tables/thoughts.md) as a `WARN_ONLY` guard-block
row (`isWarnOnly: true`); `HIGH_FEAR` emits a console warning only (no audit
row). The hard BUY→HOLD rewrite exists only on the LILITH provider lane
(`applyHardGate` in `magi-core/src/lilith.js` →
[lilith-hard-gate-events](/system/echidna-tables/lilith-hard-gate-events.md)).
Standard providers have no hard VIX block — [risk-rules](/_lilith_safe/constitution/risk-rules.md)
states `EXTREME_FEAR` BUY is system-blocked, so the standard lane diverges from
the constitution here (open for Jun: tighten the lane or amend the policy).

# Constitution basis

[MARKET REGIME AWARENESS - VIX](/system/constitution/vix-regime.md): VIX governs
size and selectivity, not direction. L6 is the warn-only layer for elevated-VIX
BUYs. The hard side-bias gating for EXTREME_FEAR is a separate enforcement
path, currently wired only into the LILITH provider lane.
