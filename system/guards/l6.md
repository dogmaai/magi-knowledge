# Purpose

Applies VIX-regime awareness (MAGI-GE-DESIGN-001-v2 §5.2). On the standard LLM
path, a BUY in an `EXTREME_FEAR` / `PANIC` regime is now **hard-blocked** per
[constitution risk-rules](/_lilith_safe/constitution/risk-rules.md)
(`EXTREME_FEAR` is SELL/SHORT only; `PANIC` is more severe and is gated
identically): the order fails with `blocked_by: 'vix_regime_layer'` and a
`BLOCKED` guard row is written to
[`thoughts`](/system/echidna-tables/thoughts.md) — resolving the earlier
warn-only divergence Jun decided to tighten (option A, 2026-09-21).

Standard-lane exceptions and degraded behavior:

- A BUY that only reduces exposure (covering an existing short) is allowed —
  positions must always be unwindable (same principle as L0 degraded mode /
  L1.7). A BUY larger than the short (a flip leg) is blocked. The check uses
  `isIncreasingExposure` against live positions.
- If the position lookup fails, the BUY fails closed (treated as
  risk-increasing).
- `HIGH_FEAR` remains warn-only — console warning, no audit row (risk-rules
  maps it to short bias, not a system block).
- SELL orders are not gated by this layer.

The retired LILITH provider lane enforced the same constitution rule earlier
via `applyHardGate` in `magi-core/src/lilith.js` (BUY→HOLD rewrite, journaled
to `lilith_hard_gate_events`; provider path removed in magi-core#494, table
dropped 2026-09-23 — see the deprecated `lilith-hard-gate-events` concept).

# Constitution basis

[MARKET REGIME AWARENESS - VIX](/system/constitution/vix-regime.md): VIX governs
size and selectivity, not direction. L6 enforces the
[risk-rules](/_lilith_safe/constitution/risk-rules.md) side restriction for
`EXTREME_FEAR`/`PANIC` on the standard LLM lane and remains warn-only for
`HIGH_FEAR`.
