# Purpose

Applies VIX-regime awareness (MAGI-GE-DESIGN-001-v2 §5.2). Unlike most layers,
L6 is **warn-only** for BUYs: a BUY in a `HIGH_FEAR` / elevated-VIX regime is
allowed but logged to `guard_blocks` with `isWarnOnly: true`. The hard VIX
blocking (e.g. BUY blocked in `EXTREME_FEAR`) is enforced elsewhere — see
[risk-rules](/_lilith_safe/constitution/risk-rules.md) and
[lilith-hard-gate-events](/system/echidna-tables/lilith-hard-gate-events.md).

# Constitution basis

[MARKET REGIME AWARENESS - VIX](/system/constitution/vix-regime.md): VIX governs
size and selectivity, not direction. L6 is the warn-only layer for elevated-VIX
BUYs. The hard side-bias gating for EXTREME_FEAR is a separate enforcement path.
