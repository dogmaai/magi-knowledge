# Purpose

Consults the PositionManager (`checkPositionManagerGuard(symbol, side)`) to veto
trades that violate position-management policy (e.g. conflicting with an
existing managed position).

# Behaviour

On veto the call returns `blocked_by: 'position_manager_guard'`.
