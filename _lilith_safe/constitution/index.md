# LILITH constitution (clean-source subset)

The immutable rules LILITH must obey, distilled into a clean-source form safe to
feed into training. These mirror the lane system prompts in
`lilith-training/scripts/distill_analysis_methods.py` and the MAGI Constitution,
restricted to the universal rules — no unit-specific performance, no picks.

* [output-rules](output-rules.md) - The verbatim `COMMON_OUTPUT_RULES` prompt tail (single source for the lane prompts).
